# Moco

[中文](README.md)

Feet sliding, motion jittering, or hands clipping through the body? Moco helps you spot these issues, check them against reference video, and preview a fix, while the original file stays untouched.

## Download

Download the latest Windows build from [Releases](https://github.com/OttoPrua/moco/releases/latest).

## System requirements

- Windows 10 or Windows 11
- 64-bit (x64)

## Installation

The installer is not signed yet. Windows may say the publisher is unknown.

If you see “Windows protected your PC”:

1. Choose “More info”.
2. Confirm the installer came from this repository’s Releases.
3. Choose “Run anyway”.
