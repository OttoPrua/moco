# Moco

[English](README.en.md)

脚底打滑、动作发抖、手穿过身体？Moco 帮你找出这些问题，对照参考视频看清楚，再预览修好的效果，原来的文件保持不动。

## 下载

[在 Releases 下载最新 Windows 版](https://github.com/OttoPrua/moco/releases/latest)。

## 系统要求

- Windows 10 或 Windows 11
- 64 位（x64）

## 安装提示

安装包暂未签名。Windows 可能弹出「未知发布者」。

若出现「Windows 已保护你的电脑」：

1. 点「更多信息」。
2. 确认安装包来自本仓库的 Releases。
3. 点「仍要运行」。
